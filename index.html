Objective & Methodology

SecureShop is an open-source vulnerable e-commerce laboratory built specifically for application security education, OWASP ZAP scanning, and college security assignments.

The 5-Step Methodology:

  1. BUILD: Explore the storefront, catalog, cart, and authentication system.
  2. ATTACK: Use the Red Team Console or manual browser tools to exploit vulnerabilities in VULNERABLE 🔴 mode.
  3. IDENTIFY: Open the Code Diff Inspector to locate exact flaw lines in code.
  4. FIX: Click "Switch to Patched Mode" in the top bar to apply security remediations (input escaping, parameterized DB queries, rigid price verification, rigid JWT key checks).
  5. RETEST & REPORT: Execute payloads again to confirm prevention, update the Retest Matrix, and export your college report.
